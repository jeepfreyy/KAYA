KAYA MODE · LOCAL AI

A few steps to get ready.

Kaya Mode uses qwen2.5:3b through Ollama on your computer. Download the software and model once; analysis then works without internet. Use Chrome or Edge 126 or later.

Windows

Open PowerShell in the repository folder and run:

powershell -ExecutionPolicy Bypass -File scripts/setup-kaya.ps1

This downloads a verified Ollama runtime and model into .kaya-runtime, starts the local server, and warms up Qwen. On later days, start it with:

powershell -ExecutionPolicy Bypass -File scripts/start-kaya-ollama.ps1

macOS

Install Ollama from its official site and Node.js 22 or later. Quit the Ollama menu-bar app if it is already running. From the repository folder:

bash scripts/start-kaya-ollama.sh

Leave that terminal open. In a second terminal:

ollama pull qwen2.5:3b
ollama run qwen2.5:3b ""

Open the practice page

With Node.js 22 or later installed, run this in another terminal:

node scripts/serve-kaya-demo.mjs

Open the practice page, open Kaya Mode, select Check local AI, then Analyze.

Choose your mode

Explain this page simplifies the readable page text. Explain selected text explains a paragraph you highlighted on the website. Help me with this form gives an overview, preparation checklist, and first step. Simplify this form on the page adds a removable guide that visits the website’s original fields in a clearer order. Click the toolbar icon again when switching websites to allow access. Drag the panel edge to resize it.

If something needs attention

  • Ollama unavailable: start the server and try again.
  • Model missing: finish the model download above.
  • Blocked origin: quit the other Ollama server and use the start script. It allows this extension’s origin only.
  • Taking too long: warm up the model, close other heavy apps, and retry. Each analysis has a two-minute limit.
  • No supported form: try the practice form. Custom widgets, embedded forms, and PDFs aren’t supported.

Keep the side panel open while analysis runs. Closing it or selecting Cancel stops the request. Analysis never fills or submits fields. Visible page text and form labels may contain personal information supplied by the website; use the fictional practice form for demonstrations.

The model’s advice may be incomplete or incorrect. Follow the actual form’s instructions.
